# Classic Google

A Chrome extension that gives you Google's classic web results back — ten blue
links, no AI Overview, no AI Mode.

****[Install it free from the Chrome Web Store →](https://chromewebstore.google.com/detail/bjdeogggojilabcimjclcgmdcedlcifi)****

---

## What it does

Every search you run goes straight to Google's plain web results. You don't
change how you search, click a filter, or remember a setting.

If you'd rather keep Google exactly as it is and only strip the AI answers out
of the page, there's a second mode that does that instead. Switch between them
from the toolbar icon, or pause the extension entirely with <kbd>Alt</kbd> +
<kbd>Shift</kbd> + <kbd>A</kbd>.

**Images, Videos, News, Maps and Shopping are left alone.** Only the main web
search is affected.

All Google country domains are covered — google.com, google.co.uk, google.de,
google.ro and forty more.

## Something not working?

**[Open an issue →](../../issues/new/choose)**

The most common problem is Google renaming a section, which stops the extension
recognising it. That's a one-line fix on my side, but I need the exact wording
Google is using in *your* language — the issue form asks for it.

Reports get fixed and shipped as normal updates.

### Why this one doesn't rot

Most extensions in this category break within months, because they look for
Google's CSS class names and Google regenerates those constantly.

This one keys off two things Google can't change without breaking its own page:
the `udm` parameter that selects plain web results, and the localized heading
text of each section — recognised in 29 languages.

When something does slip through, it gets fixed. That's the whole maintenance
promise, and it's the only thing that matters in the long run.
